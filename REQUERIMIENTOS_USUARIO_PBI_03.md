# Requerimientos de Usuario — PBI-03

## 1. Nombre del PBI

Interfaz para seleccionar productos y visualizar el total de la venta.

## 2. Historia de usuario

Como cajero de una cafetería, quiero seleccionar los productos que solicita el cliente y visualizar el total de la venta, para informarle cuánto debe pagar.

## 3. Objetivo

Diseñar una interfaz sencilla, clara y fácil de utilizar para registrar los productos de una venta y mostrar el importe total.

## 4. Requerimientos funcionales propuestos

- La interfaz debe mostrar los productos disponibles.
- El usuario debe poder seleccionar los productos para una venta.
- La interfaz debe permitir visualizar los productos seleccionados.
- Cada producto debe mostrar su nombre, precio y cantidad.
- El sistema debe presentar el total de la venta.
- La interfaz debe mostrar mensajes claros cuando no haya productos seleccionados o exista un dato inválido.

## 5. Requerimientos de usabilidad

- Los botones deben tener nombres claros.
- Los precios deben mostrarse en un formato monetario uniforme.
- El total de la venta debe ser fácil de identificar.
- La distribución debe facilitar el trabajo del cajero.
- Los mensajes de validación deben ser comprensibles.

## 6. Criterios de aceptación propuestos

- El cajero puede identificar los productos disponibles.
- El cajero puede identificar los productos seleccionados.
- La interfaz presenta el total calculado de la venta.
- La pantalla permite distinguir el precio unitario, la cantidad y el total.
- La interfaz informa claramente cuando la venta todavía no contiene productos.

## 7. Alcance pendiente de aprobación

Los productos, precios de ejemplo, forma de agregar cantidades, tratamiento de una venta vacía y reglas de cálculo deben acordarse con el Product Owner y el equipo antes de implementar la funcionalidad.
